นโยบายความเป็นส่วนตัว — Cue

2026-09-06

Cue ให้บริการโดย Rizk Corsight, LLC การ์ด บันทึก ประวัติการเรียน และการตั้งค่าจะเก็บไว้บนอุปกรณ์ ไม่มีบัญชีผู้ใช้ โฆษณา การวิเคราะห์การใช้งาน หรือพื้นที่คลาวด์ของผู้พัฒนา การสร้างการ์ดและการประมวลผลไฟล์หรือรูปภาพที่รองรับทำบนอุปกรณ์ การ์ดอาจมีข้อผิดพลาด วิธีนำเข้าแตกต่างกันระหว่าง Apple และ Android

การใช้ไมโครโฟนเป็นทางเลือก ฟังก์ชันเสียงใช้บริการของระบบและขึ้นกับอุปกรณ์ ภาษา และทรัพยากรที่ติดตั้ง Android 1.0.6 เลือกการรู้จำเสียงบนอุปกรณ์และเสียงออฟไลน์ หากไม่มีให้ใช้ปุ่มสัมผัส ระบบอาจต้องใช้อินเทอร์เน็ตเพื่อดาวน์โหลดทรัพยากรภาษา การแจ้งเตือนเป็นทางเลือกและปิดได้ในการตั้งค่าระบบ

คุณควบคุมการส่งออก การแชร์ และข้อมูลสำรองของระบบ ผู้รับและผู้ให้บริการสำรองข้อมูลดูแลสำเนาตามนโยบายของตน การลบการ์ดหรือถอนการติดตั้ง Cue ไม่ได้ลบสำเนาที่ส่งออกหรือสำรองไว้ เราไม่สามารถเข้าถึงหรือลบข้อมูลการเรียนบนอุปกรณ์ของคุณจากระยะไกล

คุณเริ่มทดลองใช้ในอุปกรณ์สามวันได้โดยไม่มีค่าใช้จ่ายหรือการสมัครสมาชิก การปลดล็อกถาวรเป็นการซื้อครั้งเดียวแบบเลือกได้ Apple หรือ Google จัดการข้อมูลสินค้า การซื้อ การตรวจสอบ การคืนเงิน และการกู้คืนการซื้อ ซึ่งอาจต้องใช้อินเทอร์เน็ต เราอาจได้รับรายงานธุรกรรมและยอดขาย แต่ไม่ได้รับรายละเอียดบัตรชำระเงิน นโยบายความเป็นส่วนตัวของร้านค้ามีผลใช้บังคับ

เว็บไซต์ช่วยเหลือนี้อยู่บน GitHub Pages ซึ่งอาจประมวลผลข้อมูลทางเทคนิคของการเข้าชมตามนโยบาย GitHub หากส่งอีเมลถึงฝ่ายช่วยเหลือ เราและผู้ให้บริการอีเมลจะได้รับข้อความและข้อมูลติดต่อเพื่อตอบกลับ เราเก็บบันทึกตามที่จำเป็นเพื่อแก้ไขคำขอและปฏิบัติตามกฎหมาย ติดต่อเรื่องความช่วยเหลือ ความเป็นส่วนตัว หรือขอลบอีเมลได้ที่ rizkcorsight@rizkcorsight.com เราจะอัปเดตหน้านี้หากแนวปฏิบัติเปลี่ยนแปลง
